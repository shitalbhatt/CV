## Structure

This is a single static HTML file with no build step or dependencies beyond Google Fonts, loaded directly in the browser.

```
index.html   — the entire site (structure, styles, and script inline)
```

## Updating the site

1. Edit `index.html` directly (either locally or using GitHub's built-in editor — click the pencil icon on the file page).
2. Commit the change.
3. GitHub Pages rebuilds automatically within a minute or two; no other steps are needed.
